# 荧光传感器图片快速处理平台

## 项目简介

Fluoro-Sensor 是一个专业级的荧光传感器图像极速分析平台，专注于荧光图像的高效处理与量化分析。该平台充分体现科技感、高效性及广泛社会价值，重点突出在机场安检和食品安全等关键领域的应用。

## 核心功能

- **极速响应**：数秒内完成背景去噪、对比度增强与荧光强度提取
- **智能量化**：自动识别荧光区域并计算相对荧光强度（RFI）
- **数据可视化**：一键生成柱状图、热力图及标准曲线
- **格式兼容**：支持 TIF, JPG, PNG 及各类专业显微镜导出格式
- **安全合规**：所有数据加密处理，保障敏感检测信息安全

## 应用场景

1. **公共安防**：机场与海关安全检测，爆炸物及危险化学品痕量判读
2. **食品安全**：农产品农药残留快速检测，现场实时高通量初筛
3. **医疗诊断**：生物芯片肿瘤标志物分析，环境重金属检测

## 安装与运行

### 前置要求

- Node.js（推荐 v14 或更高版本）
- 现代浏览器（Chrome、Firefox、Edge、Safari）

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm start
```

服务器将在 http://localhost:3000 启动

也可以直接在浏览器中打开 `index.html` 文件

## 开发说明

### 修改样式
所有样式定义在 `styles.css` 中，使用 CSS 变量方便主题定制：

```css
:root {
    --primary-bg: #1A1A2E;
    --neon-green: #39FF14;
    --neon-blue: #00FFFF;
    /* ... 更多变量 */
}
```

### 添加交互功能
JavaScript 代码在 `script.js` 中，模块化设计便于扩展：

```javascript
function initializeNewFeature() {
    // 您的功能代码
}
```

### 自定义动画
动画效果使用 CSS keyframes 和 JavaScript 结合：

```css
@keyframes customAnimation {
    /* 动画定义 */
}
```
